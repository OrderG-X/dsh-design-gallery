# 小推车招牌优化 · 小红书 5 图

1080×1440 竖版，套用「琼华设计」原有图文的骨架：深橄榄标题条 + 右上角图片搜索图标、橙色 Step 胶囊、超大深绿标题、橙色副标、底部品牌栏与轮播圆点。

## 五屏

1. `cover.html` — 封面：怎么让人一眼记住？推车在暗场亮灯展示。
2. `step1.html` — 产品力：顶部灯箱 + 底部主招牌，先给结果再给支撑。
3. `step2.html` — 转化钩子：把 10/12/13 元重排成价格阶梯。
4. `step3.html` — 场景与信任：食材实拍 + 指出「现点现做」被挡住的问题。
5. `summary.html` — 总结：先抓需求 / 再给支撑 / 加转化钩子。

## 文件

- `tokens.css` — 颜色、字体、画幅变量
- `poster.css` — 五屏共用的版式、标题、页脚、价格阶梯
- `assets/` — 推车原图与裁切（顶灯箱、底招牌、整体）

## 字体与色值

- 字体：Noto Sans SC（标题 900，正文 500/600），Step 用 Georgia 斜体
- 深橄榄 `#1a2215` · 深绿 `#0f2b00` · 橙 `#fc5300` · 暖白 `#ffffff`

## 导出

右侧「设计工作台」逐屏查看并导出 1080×1440 图片，或直接对每屏截图；页面本身没有脚本和外部依赖。
